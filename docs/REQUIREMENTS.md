# Requerimientos

## Funcionales
- Crear, listar y consultar tareas.
- Seleccionar ejecutor por tarea.
- Persistir estados y resultados.
- Ejecutar una tarea por ciclo.
- Capturar salida, errores, codigo y duracion.
- Bloquear dependencias no completadas.

## No funcionales
- Python 3.11 o superior.
- Funcionar sin Kilo, Cline o credenciales.
- No guardar secretos.
- Salida limitada para reducir tokens.
- Logs y artefactos ampliables sin romper el contrato.
