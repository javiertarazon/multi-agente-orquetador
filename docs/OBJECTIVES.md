# Objetivos

## Objetivo principal
Coordinar tareas de desarrollo mediante un orquestador local que conserve solo el contexto necesario y delegue ejecucion a Kilo o Cline.

## Alcance inicial
- Cola durable SQLite.
- CLI local.
- Worker de un solo proceso.
- Ejecutor simulado, Kilo y Cline.
- Contratos tipados y resultados resumidos.

## Fuera de alcance inicial
- Despliegue en nube.
- Ejecucion en produccion.
- Control externo directo de una sesion Copilot.
- Distribucion multi-host.
